1.4 Data quality issues found

  • Date and hour are split. Fecha always contains midnight and the actual hour is in Hora, without a leading zero. Both columns must be combined into a single xsd:dateTime value (e.g., 2020-01-01T13:00:00) before generating RDF.
  • Missing values have two different causes. Most empty cells are structural: the station does not have that sensor (for example, CO is only measured at 6 stations, and the benzene/toluene/xylene/noise columns only at Pista Silla). The rest are real gaps in a sensor that normally measures. 83,605 rows have no pollutant value at all; 70,152 of them belong to the two meteorological stations. Empty cells will not generate any observation; they must never be converted into zeros.
  • Incomplete series. Several stations do not cover the whole period: Valencia Centro starts in January 2018, Puerto Valencia covers only 2017–2020, Nazaret Meteo starts in 2020, and the two new port stations only cover 2021 (Puerto llit antic Túria has values for less than half of its hours). Molí del Sol has 43,848 rows instead of 52,608.
  • Out-of-range values. 63 relative humidity values are above 100% (maximum 107%), 198 solar radiation values are negative (minimum -7 W/m2) and 60 noise values are above 140 dB(A) (maximum 250), while 99% of noise values are below 73 dB(A). These values are physically implausible and will be flagged during data preparation (Assignment 3).
  • Redundant columns. Día de la semana and Día del mes can be derived from the date and will not be transformed.
  • No identifiers for stations. Stations are identified only by their name, which contains spaces, accents and abbreviations (e.g., Puerto Moll Trans. Ponent). Identifiers for stations will therefore have to be derived from their names.
  • Column headers in Spanish. Headers mix chemical formulae (NO2) and Spanish names (Temperatura, Ruido). The ontology will need English labels for them, and the original header can be kept as the code of each measured magnitude.

The analysis shows that the dataset contains 12 stations and 22 measured magnitudes, more than the 5 stations and 8 pollutants identified in Assignment 1 from the portal description.
